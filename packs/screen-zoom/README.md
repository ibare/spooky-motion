# 화면 확대

화면 녹화의 한 영역으로 확대해 들어갔다가 원래 화면으로 돌아오는 효과입니다. 실제 처리는 FxPlug 플러그인(`fxplug/screen-zoom`)이 하고, 이 팩은 FCP에서 보이도록 플러그인을 감싸는 템플릿을 만듭니다.

| 템플릿 | 종류 | 인스펙터 항목 |
|---|---|---|
| **화면 확대** | 효과 | 영역 고르기, 가운데, 배율, 움직임 시간, 유지 시간, 움직임 곡선(고급 / 부드럽게), 모션 블러 |

## 설치

```sh
fxplug/screen-zoom/build.sh   # 플러그인 빌드 → ~/Applications/ScreenZoom.app 설치 → 등록
./install.sh                  # 감싸는 템플릿 설치
```

설치한 뒤에는 FCP를 다시 실행합니다.

## 쓰는 법

1. 확대할 구간의 시작과 끝을 ⌘B로 자르고, 가운데 조각에 '화면 확대'를 적용합니다.
   - 구간이 시작하면 줌 인하고, 끝나기 전에 원래 화면으로 돌아옵니다. 구간 길이가 곧 확대해 머무는 시간입니다.
   - 시작만 자르고 **유지 시간**에 초를 넣어도 됩니다. 그 시간만 머문 뒤 돌아옵니다. 0이면 구간 끝까지 머뭅니다.
2. 인스펙터에서 효과를 선택하면 뷰어에 영역 사각형과 모서리 핸들이 나옵니다.
   - 사각형은 지금 프레임에 보이는 모습대로 그립니다. 다 확대한 프레임에서는 영역이 화면을 채우므로 화면 테두리에 붙어 보입니다.
   - 안쪽을 끌면 옮겨지고, 모서리를 끌면 반대쪽 모서리를 고정한 채 크기(배율)가 바뀝니다.
   - 끄는 동안만 원래 화면에서 영역 밖이 어둡게 보이고, 놓으면 확대 결과로 돌아옵니다.
3. 재생해서 확인합니다.

## 인스펙터 항목

- **영역 고르기**: 끌지 않고 원래 화면에서 영역을 보고 싶을 때 켭니다. **직접 켰으면 직접 꺼야 합니다.** 켠 채로 두면 재생과 내보내기에서도 어두운 미리 보기가 나옵니다.
- **가운데**, **배율**: 영역의 가운데(0~1)와 배율입니다. 뷰어 핸들로 바꾸면 여기 값이 따라 바뀝니다. 영역은 늘 화면 안에 있도록 맞춰집니다.
- **움직임 시간**: 줌 인, 줌 아웃에 걸리는 시간(초)입니다. 기본 0.6초. 0이면 바로 바뀝니다.
- **움직임 곡선**
  - 고급(기본): 임계 감쇠 용수철. 부드럽게 출발해 빠르게 들어가고, 길고 부드럽게 멈춥니다. 출렁임은 없습니다.
  - 부드럽게: 대칭 이징(easeInOutCubic).
- **모션 블러**: 움직이는 동안 카메라 셔터처럼 잔상을 넣습니다(기본 켬). 멈춘 프레임과 구간의 첫·마지막 프레임은 원본 그대로입니다.

## 움직임

- 영역 가운데(목표)가 화면 가운데로 곧게 이동하는 동안 배율이 함께 커집니다. 이동과 확대가 같은 곡선을 따릅니다.
- 배율은 처음부터 끝까지 같은 빠르기로 보이도록 로그 비율로 키웁니다. 다만 화면 밖이 드러나지 않을 만큼은 앞당깁니다.
- 영역이 화면 가장자리에 붙어 있으면 바깥에 보여 줄 화면이 없습니다. 그래서 줌이 이동보다 조금 앞서 보입니다.

## 주의

- 효과는 클립 원래 해상도에서 확대합니다. FCP는 클립의 변형·자르기를 효과 다음에 적용합니다.
- 플러그인의 UUID(`fxplug/screen-zoom/Plugin/Info.plist`)를 바꾸면, 이 효과를 쓰던 타임라인 항목이 플러그인을 찾지 못합니다.

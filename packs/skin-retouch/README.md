# 피부 보정

강의 영상에서 강사 얼굴 피부의 잡티를 줄이는 효과입니다. 실제 처리는 FxPlug 플러그인(`fxplug/skin-retouch`)이 하고, 이 팩은 FCP에서 보이도록 플러그인을 감싸는 템플릿을 만듭니다.

| 템플릿 | 종류 | 인스펙터 항목 |
|---|---|---|
| **피부 보정** | 효과 | 보기(결과 / 피부 마스크 / 잡티 표시 / 번들거림 표시), 정도, 크기, 결 살리기, 잡티 지우기, 번들거림 줄이기, 피부색 범위, 수염 영역 제외 |

## 설치

```sh
fxplug/skin-retouch/build.sh   # 플러그인 빌드 → ~/Applications/SkinRetouch.app 설치 → 등록
./install.sh                   # 감싸는 템플릿 설치
```

설치한 뒤에는 FCP를 다시 실행합니다.

## 진행 단계

1. 뼈대: 효과가 뜨고 플러그인이 그리는지 확인했습니다.
2. 피부 마스크: 얼굴 특징점(Vision)과 피부색으로 피부만 고릅니다. '보기'를 '피부 마스크'로 두면 고른 곳만 원래 색으로 보입니다.
   - 얼굴 영역: 윤곽과 이마에서 눈, 눈썹, 입술을 뺍니다. '수염 영역 제외'를 켜면 입과 턱 주변도 뺍니다.
   - 피부색: 그 사람의 볼과 이마에서 색을 뽑아 기준으로 삼습니다. 판정은 흐린 저해상도 영상으로 해서 잡티 자리에 구멍이 나지 않게 합니다.
   - 밝기: 피부보다 많이 어두운 곳(안경테, 눈썹, 머리카락)은 원본 해상도로 거릅니다.
   - 피부가 덜 덮이면 '피부색 범위'를 올리고, 배경이나 머리카락이 들어오면 내립니다.
3. 매끈하게: 가이드 필터로 낮은 대비의 얼룩(잡티, 붉은 기)을 평평하게 하고, 눈꺼풀이나 콧날 같은 경계는 남깁니다.
   - **정도**: 원본과 섞는 비율입니다. 기본 60%.
   - **크기**: 평평하게 만들 얼룩의 크기를 얼굴 너비에 대한 비율로 정합니다. 기본 2.5%. 큰 기미까지 누그러뜨리려면 올립니다.
   - **결 살리기**: 모공 크기의 미세한 결을 되돌리는 정도입니다. 기본 50%. 플라스틱처럼 보이면 올립니다.
4. 잡티 골라 지우기: 둘레 8방향보다 모두 어둡거나 붉은 작은 점을 찾아 둘레 피부색으로 메웁니다.
   - 그늘진 경계나 주름은 한쪽 방향이 똑같이 어두워서 잡히지 않습니다. 얼굴 너비의 1%보다 큰 점(큰 점, 콧구멍)도 잡히지 않습니다.
   - 안경테, 눈썹, 머리카락 둘레에서는 잡티로 보지 않습니다.
   - **잡티 지우기**: 메우는 정도입니다. 기본 70%. '보기'를 '잡티 표시'로 두면 잡티로 판정한 곳이 빨갛게 보입니다.
   - 넓게 퍼진 기미는 점이 아니라 이 단계의 대상이 아닙니다. 3단계의 **크기**를 올려 누그러뜨립니다.
5. **번들거림 줄이기 (지금)**: 반사광을 눌러 두고 크게 흐린 '기준 피부'보다 밝고 흰빛인 곳(이마, 콧등, 코끝, 광대)의 밝기를 덜어내고 피부색을 되돌립니다.
   - 조명을 잘 받았을 뿐인 피부는 채도가 남아 있어서 덜 걸립니다.
   - 판정은 흐린 영상으로 해서 넓은 영역으로 부드럽게 잡힙니다.
   - 모니터 빛이 비친 보랏빛 반사광도 잡도록, 피부색 범위를 두 배로 넓힌 마스크를 씁니다. 안경알 반사처럼 색이 아주 다른 것은 빠집니다.
   - **번들거림 줄이기**: 기본 50%. 반사광을 모두 없애면 얼굴의 입체감이 사라지므로 일부를 남깁니다. '보기'를 '번들거림 표시'로 두면 판정한 곳이 파랗게 보입니다.

## 주의

- PIP 레이아웃과 함께 쓸 때는 **PIP 레이아웃보다 위에** 적용합니다. 화면을 줄이기 전의 원래 해상도에서 보정해야 합니다.
- 플러그인의 UUID(`fxplug/skin-retouch/Plugin/Info.plist`)를 바꾸면, 이 효과를 쓰던 타임라인 항목이 플러그인을 찾지 못합니다.

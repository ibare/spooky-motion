# 피부 보정

강의 영상에서 강사 얼굴 피부의 잡티를 줄이는 효과입니다. 실제 처리는 FxPlug 플러그인(`fxplug/skin-retouch`)이 하고, 이 팩은 FCP에서 보이도록 플러그인을 감싸는 템플릿을 만듭니다.

| 템플릿 | 종류 | 인스펙터 항목 |
|---|---|---|
| **피부 보정** | 효과 | 보기(결과 / 피부 마스크), 피부색 범위, 수염 영역 제외 |

## 설치

```sh
fxplug/skin-retouch/build.sh   # 플러그인 빌드 → ~/Applications/SkinRetouch.app 설치 → 등록
./install.sh                   # 감싸는 템플릿 설치
```

설치한 뒤에는 FCP를 다시 실행합니다.

## 진행 단계

1. 뼈대: 효과가 뜨고 플러그인이 그리는지 확인했습니다.
2. **피부 마스크 (지금)**: 얼굴 특징점(Vision)과 피부색으로 피부만 고릅니다. '보기'를 '피부 마스크'로 두면 고른 곳만 원래 색으로 보입니다. '결과'는 아직 원본 그대로입니다.
   - 얼굴 영역: 윤곽과 이마에서 눈, 눈썹, 입술을 뺍니다. '수염 영역 제외'를 켜면 입과 턱 주변도 뺍니다.
   - 피부색: 그 사람의 볼과 이마에서 색을 뽑아 기준으로 삼습니다. 판정은 흐린 저해상도 영상으로 해서 잡티 자리에 구멍이 나지 않게 합니다.
   - 밝기: 피부보다 많이 어두운 곳(안경테, 눈썹, 머리카락)은 원본 해상도로 거릅니다.
   - 피부가 덜 덮이면 '피부색 범위'를 올리고, 배경이나 머리카락이 들어오면 내립니다.
3. 매끈하게: 가장자리를 보존하는 흐림과 결 되살리기를 넣습니다.
4. 잡티 골라 지우기
5. (선택) 번들거림 줄이기

## 주의

- PIP 레이아웃과 함께 쓸 때는 **PIP 레이아웃보다 위에** 적용합니다. 화면을 줄이기 전의 원래 해상도에서 보정해야 합니다.
- 플러그인의 UUID(`fxplug/skin-retouch/Plugin/Info.plist`)를 바꾸면, 이 효과를 쓰던 타임라인 항목이 플러그인을 찾지 못합니다.

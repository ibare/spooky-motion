# 강의 PIP

강의 영상(화면 캡처 + 강사 카메라)에서 강사 화면(PIP)의 위치와 크기를 장면마다 바꾸고, 바뀔 때 자연스럽게 움직이게 하는 팩입니다.

| 템플릿 | 종류 | 인스펙터 항목 |
|---|---|---|
| **PIP 레이아웃** | 효과 | 배치(크게 / 작게 · 아래 / 작게 · 위), 좌우 반전, 인물 위치, 인물 크기, 모서리 둥글기 |
| **PIP 전환** | 트랜지션 | 움직임(고급 / 부드럽게) |

## 편집 흐름

1. 화면 캡처와 강사 클립을 한 타임라인에 올리고 컷편집을 끝냅니다.
2. 강사 클립들을 **컴파운드 클립**으로 묶습니다.
3. 컴파운드에 **PIP 레이아웃** 효과를 적용합니다. 처음에는 '작게 · 아래'로 시작합니다.
   - 강사 영상을 뒤집어 쓰면 **좌우 반전**을 켭니다.
   - 얼굴이 창 가운데 오도록 **인물 위치**와 **인물 크기**를 맞춥니다.
   - 자르기 전에 한 번만 맞추면 잘린 조각들이 모두 이어받습니다.
4. 배치가 바뀌는 지점마다 **Command+B**로 자르고, 조각마다 **배치**를 고릅니다. 여러 조각을 함께 선택해서 한 번에 바꿀 수도 있습니다.
5. 트랜지션 브라우저에서 **PIP 전환**을 오른쪽 클릭해서 **기본값으로 설정**합니다.
6. 자른 지점들을 클릭하거나 Command+클릭으로 고르고 **Command+T**를 누릅니다. 트랜지션이 앞뒤 배치를 스스로 알아내서 움직입니다.

## 주의

- **클립의 변형·자르기는 꺼 두세요.** FCP는 클립 자체의 변형·자르기를 효과보다 나중에 적용합니다. 켜 두면 PIP가 잘리거나 엉뚱한 곳으로 갑니다. 컴파운드 안의 강사 클립에도 넣지 마세요.
- **컴파운드 맨 앞과 맨 끝에는 트랜지션을 넣지 마세요.** 한쪽에 조각이 없으면 전환하는 동안 PIP가 사라집니다. 조각을 통째로 선택하고 Command+T를 누르면 양 끝에도 들어가니 지워 주세요.
- **트랜지션 길이**는 FCP가 정합니다.
  - 하나만 바꾸려면 트랜지션을 선택하고 **Control+D**를 누르거나 양 끝을 끕니다.
  - 기본 길이는 **Final Cut Pro > 설정 > 편집**에서 바꿉니다.
- **움직임**
  - 고급: 거의 티 나지 않게 튕기는 용수철에, 살짝 휘는 경로와 들었다 놓는 그림자가 더해집니다.
  - 부드럽게: 천천히 출발해서 천천히 멈춥니다.
- 템플릿을 새로 설치한 뒤에는 **FCP를 다시 실행**하세요.

## 조정

모든 값은 `generate.py` 맨 위 **설정** 구역에 있습니다. 고친 뒤 리포 맨 위에서 `./install.sh`를 실행하세요.

| 바꾸고 싶은 것 | 설정 |
|---|---|
| 배치 위치·크기 | `LAYOUTS`, `LARGE_W`, `LARGE_H`, `ROUNDNESS` |
| 처음 적용할 때의 배치 | `DEFAULT_LAYOUT` |
| 창 안 인물의 기본 확대율 | `FRAMING_SCALE` |
| 움직임 종류와 처음 값 | `MOTION_STYLES`, `DEFAULT_STYLE` |
| 고급 움직임 (튕김, 휘는 정도, 그림자) | `PREMIUM` |

배치를 바꿔서 서로 너무 겹치면 생성기가 "탐침 자리가 부족합니다"라는 오류를 냅니다. 트랜지션이 앞뒤 배치를 구별할 자리가 없다는 뜻이니 배치를 조금 떨어뜨리세요.

## 동작 원리 (요약)

- **효과**: [둥근 창(스텐실 알파) + 강사 영상]을 담은 그룹을 팝업 리그가 배치별 위치·배율로 옮깁니다. 모든 배치가 같은 비율이라 전환 중에도 모양이 닮은꼴로 움직입니다.
- **트랜지션**: 앞(X)과 뒤(Y) 배치 조합 9가지를 각각 그룹으로 둡니다.
  - 앞뒤 화면에서 각 배치 자리의 한 점을 확대한 '탐침'으로 실제 조합에 맞는 그룹만 남깁니다(이중 실루엣, `docs/ozml-notes.md` 9절).
  - 남은 그룹은 원래 크기가 더 큰 쪽 화면 하나만 옮기고 키우거나 줄입니다.
